# Techniques within the constitutional boundary
All techniques here are offline. Existing copied firmware, drivers, libraries and
retained captures are legitimate inputs; no physical GPU access or hardware service.

1. Hash-keyed container/archive/ELF parsing, exact bounds and architecture mapping.
2. Driver/loader source tracing to build a versioned executable schema.
3. Disassembly/decompilation with instruction checks and explicit address domains.
4. String cross-references and dispatch-table recovery as leads with retained excerpts.
5. Same-architecture function/table matching across neighboring versions.
6. Cross-board/generation comparison with compatibility differences named.
7. Dataflow/taint reasoning from known API output through units, selectors and sentinels.
8. CPU-only emulation of isolated routines using synthetic memory and transport fixtures.
9. Existing trace/log decoding with status, direction, length and truncation checks.
10. Contradiction/claim matrices comparing vendor, Linux/nouveau/nova and independent RE.
11. Synthetic malformed-input, boundary and metamorphic tests of parsers/decoders.
12. Reproducible finding notes with hashes, source pins, uncertainty and next discriminator.

Static analysis of setters, boot verification, fuse logic and private protocols is in scope.
Invoking those mechanisms on hardware is not. There is no register peek, command sweep,
live debugger/tracer, firmware swap, bypass attempt or bench experiment in this list.
