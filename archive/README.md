# Archive

This directory preserves earlier reports and working notes so their claims can
be checked against later corrections.

- [Pre-constitution reports](2026-10-21-pre-constitution/) contain the original
  narratives replaced during the safety and evidence review.
- [Workflow notes](2026-10-21-workflow-notes/) contain the former root-level worker
  prompt, roadmap, techniques list, source collection, reviews, validation record
  and research log. Their original bytes are recorded in `manifest.json`.

Some documents describe retired tools or superseded hardware procedures. Current
project rules are in [CONSTITUTION.md](../CONSTITUTION.md), and factual retractions
are in [CORRECTIONS.md](../CORRECTIONS.md). Relative links inside archived files
reflect their original locations. Use the [main README](../README.md) for current
navigation.
