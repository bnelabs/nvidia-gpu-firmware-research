# Single-card history — descriptive comparisons only
Use retained observations or explicitly requested, low-rate documented monitoring under
[CONSTITUTION.md](../CONSTITUTION.md). No autostart, background installation, synthetic load,
polling burst, configuration change or new live getter is authorized by this document.

Single-card history can describe changes in comparable workload/version/context windows.
It cannot by itself diagnose silicon aging, fan bearing wear, connector oxidation, VRM
aging or a failed component. Public configured clock offsets are not measured rail voltage;
fan percent is not tachometer RPM. Missing counters remain missing.

Record identity and driver/firmware, API field/units/status, timestamp, natural workload and
ambient context if known. Compare distributions only when those contexts match. State sample
counts, missingness and uncertainty. A changed metric is a lead with competing explanations.

No accuracy/false-alarm threshold, population minimum, anonymous-upload guarantee or
commercial health baseline has been validated here. Crowdsourcing and external upload are
outside the current task; no data should be transmitted automatically.
