# Question and stopping rule

Resolve the object/type and entry-getter boundaries left by CO-08, then locate
one writer of the returned entry's `+0x34` word. Use immutable class IDs and
factory arguments as new discriminators; do not repeat untyped displacement
scans. Stop at a demonstrated earlier input record if its origin is not proved.

Work from merged main `6f8e387a693a03f9f5d9ec1f3e841f4c1b347292` in a new
worktree/branch. Leave the original dirty checkout, publication checkout and
their branch heads intact. Copy retained files without replacing different
existing content. No hardware collection or experimental calls.

Record raw bytes, hashes, file/firmware address domains, exact source commits,
bounded synthetic execution, source disagreements and unresolved alternatives.
Run the CPU-only repository gate and replay deterministic outputs before
promoting the finding. A matching class ID does not transfer a public host
object layout into closed firmware.
